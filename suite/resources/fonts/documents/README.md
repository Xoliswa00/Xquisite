# Document fonts

Embedded locally for PDF generation (see `resources/views/components/document-layout.blade.php`
and `docs/document-design-standard.md` §5) — no CDN fetch at render time.

- **Public Sans** — body/data face. SIL Open Font License. https://fonts.google.com/specimen/Public+Sans
- **Libre Caslon Text** — masthead/document-title face. SIL Open Font License. https://fonts.google.com/specimen/Libre+Caslon+Text

Both free for commercial use and embedding under the OFL.
